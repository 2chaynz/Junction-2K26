# T? dev.mjs: friendly error when port 8000 is busy

- **Goal:** a second `node scripts/dev.mjs` says the port is taken and how to free it, instead of Python's `Errno 10048` / `Address already in use`.
- **Files:** `scripts/dev.mjs`.
- **Needs:** none.
- **Done when:** port busy → exit 1 before any install or build, with OS-specific commands to find and stop the process.
- **Verify:** start any listener on 127.0.0.1:8000, run `node scripts/dev.mjs` → prints the message, exit 1.
