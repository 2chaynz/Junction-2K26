# T? IFC floors: storey picker, 2D plan per floor, toggles, element info

- **Goal:** pick a floor of a BIM model and see it in 3D or as a 2D plan generated from the model; answers jump to their floor. Category toggles and click-for-properties so a human can check the numbers. Fix flickering (z-fighting).
- **How:** storeys + containment from web-ifc (IfcRelContainedInSpatialStructure). 3D: hide other storeys. 2D: orthographic top view, clipping plane ~1.2 m above the storey level. Auto-pick the storey named in the question / evidence. Toggles: walls, doors, windows, slabs, spaces, other. Click → type, name, storey, quantities. Flicker: logarithmic depth buffer, tighter near/far, polygonOffset on overlays.
- **Files:** `web/src/Model3D.tsx`, `web/src/model3d.css` (new, imported by Model3D).
- **Needs:** none.
- **Done when:** esplanades IFC: storey list shows, 1.korrus in 3D and 2D, door count question opens 1.korrus with doors red, no flicker while orbiting.
- **Verify:** `cd web && npm run build`; run server, steps above.
