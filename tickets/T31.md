# T31 What changed view: revision diff in the UI

- **Goal:** on a sheet with an earlier issue (`sitelens/diff_pairs.json`), a "What changed" toggle marks every changed region on the plan and lists the changes with their quantities (T15 + T23 output).
- **Why:** construction-industry feedback: finding changes in a new drawing issue is their biggest annoyance. Backend already exists; this makes it visible in the demo.
- **Files:** `web/src/Changes.tsx` (new), `web/src/App.tsx`, `web/src/Viewer.tsx`, `web/src/styles.css`.
- **Needs:** T28 (touches `App.tsx`).
- **Done when:** picking A-801 shows the toggle; on, it highlights the changed regions in a distinct colour and lists "+3 / -6 door marks", schedule edits, etc.; click a list row → zooms to its box. Sheets without a pair show no toggle.
- **Verify:** `cd web && npm run build`; run the server, open A-801, toggle "What changed", check boxes against the old sheet by eye.
