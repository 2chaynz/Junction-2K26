# T? Motion: living UI, still professional

- **Goal:** quick feedback and data that animates in, without hurting readability. User-picked set: press feedback + sliding tab underline, hover lift on cards/rows, benchmark bars grow + numbers count up on view (rows replay on tab switch), sections fade up once, wireframe building loader for 3D models, answer value counts up.
- **Rules:** 120-250 ms controls, 400-700 ms reveals, ease-out, no bounce; off under prefers-reduced-motion; individual scale/translate so component transforms are untouched.
- **Files:** `web/src/motion.tsx`, `web/src/motion.css` (new); one-line hooks in `main.tsx`, `App.tsx` (tab nav), `Benchmark.tsx`, `HowItWorks.tsx`, `Model3D.tsx` (loading overlay), `Chat.tsx` (answer value).
