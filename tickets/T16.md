# T? Agent heartbeat, stale flag, needs-human lane, worker loop

- **Goal:** everyone sees what each agent is doing right now; idle agents pull the next ticket; humans see only what needs them.
- **Files:** `scripts/status.mjs`, `board/serve.mjs`, `board/index.html`, `.claude/settings.json`, `.claude/commands/work.md`, `AGENTS.md`.
- **Needs:** none.
- **Done when:**
  - `status.mjs beat [Tn] "<doing>"` records a heartbeat on the `beats` branch (not main, so no notices or history noise).
  - A PostToolUse hook beats automatically, at most every 5 min, without blocking the agent.
  - `show` prints last beat per doing ticket and flags stale (>15 min).
  - Board shows beat text/age per ticket and a "Needs a human" lane: blocked, review/open PRs, BLOCKING cross-reviews, stale agents.
  - `AGENTS.md` documents the worker loop and the beat rule; `/work` command runs one loop iteration.
- **Verify:** `node scripts/status.mjs beat T<n> "test"` then `show`; `node board/serve.mjs` and open the board.
