# T? Draw on the sheet to ask: "what is this?", "area of this room?"

- **Goal:** ChatGPT-style highlighter on the drawing. User paints over a spot, then asks; the answer is about that spot only.
- **How:**
  - UI: "Mark" tool in the viewer; freehand brush in sheet coords; "Marked area ×" chip in the composer; mark sent with the question.
  - API: `/api/ask(/stream)` take optional `region: {page, bbox, polygon}` (bbox units).
  - `sitelens/region.py`: area/room label inside the mark (vector text) → answer with that label as evidence; counts → normal router answer, evidence kept inside the mark, value recounted; else ("what is this?") VLM on the crop + text found inside it.
- **Files:** `sitelens/region.py` (new), `sitelens/server.py` (region field), `web/src/Sketch.tsx` + `web/src/sketch.css` (new), small hooks in `web/src/Viewer.tsx`, `web/src/Chat.tsx`, `web/src/App.tsx`, `web/src/api.ts`, `web/src/types.ts`, `CONTRACT.md`, `tests/test_region.py`.
- **Overlap:** T46 (Viewer draw tools), T39 (Chat, server). Keep edits there to a few lines.
- **Needs:** none.
- **Done when:** Swiss plan: paint a room, "what's the area of this room?" → its m² label circled; "what is this?" on a symbol → short description; "how many doors here?" counts only inside the mark.
- **Verify:** `python tests/test_region.py`; open :8000, Mark, ask.
