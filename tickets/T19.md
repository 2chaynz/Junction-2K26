# T? Room-label OCR for raster plans: bedrooms, baths, WCs, room counts

- **Goal:** count rooms by reading their labels, like VLMs do, at CPU cost. Today the detector treats rooms as objects learnt from Finnish labels. On AECV-Bench (T17) it undercounts rooms in 98/120 plans, bedrooms 53% vs VLMs 93%, toilets 66% vs 82%.
- **Files:** `sitelens/ocr.py` (new: OCR + label lexicon), `sitelens/paths/detector.py` (room-count questions only), `requirements.txt` (+ `rapidocr-onnxruntime`), `eval/aecv.py` + `eval/aecv_report.md` (rerun numbers).
- **Needs:** T6 (done). Tell johanseneuson before touching `detector.py` (T5 retrain is in flight; weights only, no code overlap expected).
- **Steps:**
  1. `sitelens/ocr.py`: `words(path) -> [(text, conf, bbox)]`, cached per image. rapidocr-onnxruntime on CPU, tile large images (>2000 px) with overlap; dedupe boxes at tile edges.
  2. Lexicon: label → room type, case/accent-insensitive, whole-word. Start with fi (MH, KH, WC, S/SAUNA, K/KEITTIÖ, ET, OH, VH, PARV), fr (CHAMBRE, SDB, BAINS, WC, CUISINE, SEJOUR), en, de (SCHLAFZIMMER, BAD, WC, KÜCHE), it, da, et. Include numbered variants (`MH1`, `CHAMBRE 2`).
  3. In `detector.answer`, for bedroom / bath / WC / sauna / kitchen counts: OCR count if it finds ≥1 matching label, else current detector count. Evidence = one box per label read, `kind: "text"`.
  4. Room count (Space / "how many rooms"): count area labels (`\d+[.,]\d+\s*m[²2]`) as a second signal; when OCR and detector disagree, lower confidence (feeds T12).
  5. Tune any threshold or rule on the `rest` split only (`eval/split.py`). Never on dev, never on AECV.
- **Done when:** `python -m eval.score --source cubicasa5k --split dev` room-type questions no worse than today, overall cubicasa ≥ today; AECV bedroom/toilet up; numbers in `eval/aecv_report.md`; one LOG line.
- **Verify:** `python -m eval.score --source cubicasa5k --split dev` and `AECV_DATA=... python -m eval.aecv`. Check: `bash scripts/check.sh` passes without the dataset (OCR import lazy).
- **Stretch (separate ticket if started):** wall-mask room segmentation (close door gaps with detector door boxes, count enclosed regions) → room polygons as evidence; room counted when a region holds a label.
