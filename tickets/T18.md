# T? Auto-close tickets when their PR merges

- **Goal:** a `review` ticket becomes `done` as soon as its branch's PR is merged, without anyone remembering.
- **Files:** `scripts/status.mjs`, `.github/workflows/close-merged.yml`, `AGENTS.md`.
- **Needs:** none.
- **Done when:**
  - `status.mjs close-merged` sets every `review` ticket whose branch has a merged PR to `done`, in one commit.
  - GitHub Action runs it on every merged PR into main.
  - `show` runs it too (fallback if Actions can't push), then prints the fresh table.
- **Verify:** set a merged ticket back to `review`, run `close-merged` → it flips to `done`. After merge, merging any PR closes its ticket within ~1 min.
