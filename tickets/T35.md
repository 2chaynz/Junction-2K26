# T? Cross-review script that finds Codex

- **Goal:** `codex exec` in AGENTS.md fails on Windows machines where Codex came with the ChatGPT desktop app: `codex.exe` lives in `%LOCALAPPDATA%\OpenAI\Codex\bin\<hash>\`, not on PATH. Agents then wrongly fall back to Claude.
- **Files:** `scripts/xreview.sh` (new), `AGENTS.md` (PR step 4).
- **Needs:** none.
- **Done when:** `bash scripts/xreview.sh <pr>` finds Codex on PATH or in the app folders, runs the review, posts the comment; Claude fallback only when no Codex binary exists.
- **Verify:** `bash scripts/xreview.sh --which` prints the binary it would use.
