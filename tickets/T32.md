# T32 Takeoff list: every door, window, column, beam, wall type with dimensions

- **Goal:** one table per drawing/model: element, type, dimensions (w×h, length, thickness), count, level. Each row links to its evidence (IFC guid or box). CSV download.
- **Why:** construction-industry feedback: they want a list of all pieces and wall thicknesses, not one question at a time.
- **Sources:** IFC (ifcopenshell: IfcDoor/IfcWindow OverallWidth/Height, IfcColumn/IfcBeam profile + length, IfcWall/IfcWallStandardCase thickness grouped by type). 2D: schedule tables (T11) where present, detector counts otherwise (count only, no dimensions; say so).
- **Files:** `sitelens/takeoff.py` (new), `sitelens/server.py` (`GET /api/takeoff?path=` → rows, `&format=csv`), `web/src/Takeoff.tsx` (new), `web/src/App.tsx` (tab), `tests/test_takeoff.py` (new), `CONTRACT.md` (endpoint).
- **Needs:** T31 (touches `App.tsx`).
- **Done when:** an IFC model shows doors/windows with sizes, columns/beams, and walls grouped by thickness; counts match the IFC path's answers to Stoa count questions; CSV opens in Excel.
- **Verify:** `python tests/test_takeoff.py`; `curl "localhost:8000/api/takeoff?path=data/ifc_models/<file>.ifc&format=csv"`; open the Takeoff tab.
