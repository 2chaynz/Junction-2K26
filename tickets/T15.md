# T15 Revision diff: what changed between two issues of a sheet

- **Goal:** pick two versions of the same sheet → list of changes (text, schedule rows, geometry) with red/green boxes on the plan. Stoa said their own product still struggles with this.
- **Why it's feasible:** opening_design has 40 sheets with more than one dated PDF issue, all vector (no OCR). Best pairs:
  - Sports_Complex A-201 permit (2015-08-14) → Addendum 1 (2016-02-10): polycarbonate panel → phenolic, Class A flame spread.
  - Sports_Complex A-801 permit → Current Set: door schedule and wall-type changes (A-801 already has Stoa questions).
  - Vacation_Rental S400/S401: 4 issues in 16 days (permit → structural review → bid).
  - Crema_Cafe A-100 v2 → v3: v3 has no text layer, so only the geometry diff works there.
- **Method:** PyMuPDF on both pages. Words: match by text + position → added / removed / moved. Vector paths: hash per path, unmatched = changed, cluster into boxes. Schedules: reuse T11 table rows, diff by door number.
- **Output:** `Answer`, with `method: "diff"` and one Evidence per change (`label: "door 121.A width 3'-0\" → 3'-6\""`, bbox on the new sheet).
- **Files:** `sitelens/paths/diff.py`, `sitelens/diff_pairs.json` (curated sheet pairs), `tests/test_diff.py`. UI hook: one `POST /api/diff {"old","new"}` route, agreed with T8 owner.
- **Needs:** none to start. T11 for the schedule-row diff.
- **Done when:** the 3 Sports_Complex/Vacation_Rental pairs return correct change lists that a human has checked; the demo shows the A-201 addendum with boxes.
- **Verify:** `python -m sitelens.paths.diff "<old.pdf>" "<new.pdf>"` prints the changes; compare to the drawings by eye.
- **Not scored:** Stoa's questions contain no revision questions. This is for creativity and the pitch, not accuracy.
