# T1 Project scaffold

- **Goal:** runnable skeleton for the chosen medium (firmware, app, service, or a mix).
- **Files:** everything (first ticket only).
- **Needs:** `DECISION.md` filled.
- **Done when:** `bash scripts/check.sh` builds it; `AGENTS.md` Run section filled; `CONTRACT.md` parts and interfaces listed.
- **Verify:** fresh clone → follow the Run section → it builds and starts (or flashes and responds).
