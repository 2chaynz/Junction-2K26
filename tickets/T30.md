# T? Scorer: live progress + resume

- **Goal:** long paid scorer runs show progress and survive kills. A hung T20 Gemini run sat 100 min with an empty results file and no output.
- **Files:** `eval/score.py`, `eval/selftest.py`.
- **Needs:** none.
- **How:**
  - Flush each results line; print `i/n, elapsed, €` to stderr every 10 questions (now every 200).
  - `--resume`: read the existing `eval/results/<name>.jsonl`, skip questions already in it (key: path + question), append, and build the table from all rows.
- **Done when:** a run killed halfway and restarted with `--resume` pays only for the missing questions and prints the same table as an uninterrupted run.
- **Verify:** `python -m eval.score --source ifc_models --limit 20 --name r`, Ctrl-C at ~10, rerun with `--resume`; row count = 20, no duplicates.
