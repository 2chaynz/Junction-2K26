# T? Live reasoning in chat: verifiable steps while answering

- **Goal:** while a question runs, the chat shows a "Thinking" block that fills live with real steps (reader tried / skipped and why, what was found, the arithmetic), in plain words. After the answer it collapses to "Reasoned in Xs · N steps", expandable. Steps that use an evidence item link to its [n] mark, so every answer can be checked on the drawing (or the 3D model for IFC, T34).
- **How:** `router.answer(path, q, on_step=None)` calls `on_step(text)` per path tried/skipped/failed; paths' trace lines are sent as steps too. `POST /api/ask/stream` returns NDJSON: `{"step": "..."}` lines, then `{"answer": {...}}` (same body as `/api/ask`). `/api/ask` unchanged.
- **Files:** `sitelens/router.py`, `sitelens/server.py`, `web/src/Chat.tsx`, `web/src/api.ts`, `web/src/types.ts`, `web/src/App.tsx`, `web/src/styles.css`, `CONTRACT.md`.
- **Needs:** T34 (shares App.tsx, styles.css).
- **Done when:** ask a Swiss area question and an IFC count question → steps appear one by one, then the answer; expanding shows all steps with [n] links that highlight the mark.
- **Verify:** `bash scripts/check.sh`; run server + `npm run dev`, steps above.
