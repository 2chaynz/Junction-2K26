# T? Reasoning stream backend: router steps + /api/ask/stream

- **Goal:** backend half of T36. The router reports each step as it happens, in plain words, and the server streams them so the chat can show live reasoning.
- **How:** `router.answer(path, q, on_step=None)`; `on_step({"text", "path", "ev"?})` per path tried / skipped / failed / answered, then each trace line of the winning path. `POST /api/ask/stream` → NDJSON `{"step": {...}}` lines, then `{"answer": {...}}` (same body as `/api/ask`). `/api/ask` unchanged.
- **Files:** `sitelens/router.py`, `sitelens/server.py`, `CONTRACT.md`, `tests/test_stream.py`.
- **Needs:** none.
- **Done when:** `curl -N -X POST localhost:8000/api/ask/stream -d '{...}'` prints steps one per line, then the answer.
- **Verify:** `bash scripts/check.sh`; curl above on a Swiss and an IFC question.
