# T? DrawingVQA: whole-sheet VLM vs our crop pipeline

- **Goal:** outside proof that our method fixes the failures in DrawingVQA (arXiv 2607.15418). Same model, same 92 questions: whole sheet vs crops + evidence. Report per depth R1/R2/R3. Context: `context/research-drawings.md`.
- **Source:** https://huggingface.co/datasets/S2-MIND/DrawingVQA. 33 US structural drawing sets, 92 expert questions, tagged knowledge / ocr / reasoning, some multiple choice. Check the dataset card licence first. Download outside the repo like the Stoa dataset; never commit their files.
- **Why not score Sindri end to end:** structural sheets (footings, beams, welds). Detector is floor-plan only, vector/IFC paths expect Stoa files. Most questions would reach the VLM fallback anyway.
- **Files:** `eval/drawingvqa.py` (new: loader + runner + table), `eval/drawingvqa_report.md` (new, results only). Don't edit `sitelens/paths/*`; need a change there → add a ticket.
- **Needs:** T13 (crop renderer), T20 (VLM backends). Use T14 index if merged; skip if not.
- **Steps:**
  1. `DRAWINGVQA_DATA=<download>` env var. Map each question to its sheet image(s) and level R1/R2/R3 (paper's depth labels; check the card for the field name).
  2. Baseline: one model (Gemini via T20 registry) on the whole sheet, paper-style prompt.
  3. Ours: same model through the T13 crop path; record evidence boxes and trace.
  4. Scoring: multiple choice = exact option match; free text = normalised exact match, LLM judge only if needed (say which in the report).
  5. Table: accuracy per level for both runs + €/question. Add the paper's Gemini 2.5 Pro row (80.6 / 76.5 / 55.6) for reference, marked as theirs.
  6. Note which failure types the crops fixed or didn't (grid tracing, first-link stop, cross-sheet).
- **Rules:** evaluation only. No prompt tuning on these 92 questions; if a prompt is changed after a first run, report both runs.
- **Expect:** small gains on R1, biggest on R2/R3 if crops work. Report losses honestly.
- **Time box:** done before feature freeze Sat 22:00, else drop and log why.
- **Done when:** `eval/drawingvqa_report.md` merged; one LOG line with R1/R2/R3 whole-sheet vs crop.
- **Verify:** `DRAWINGVQA_DATA=... python -m eval.drawingvqa` reproduces the report.
