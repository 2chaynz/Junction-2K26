# T? Home: BIM project cards spin in 3D (PyVista turntables)

- **Goal:** on the Home start screen, each BIM project card shows its model turning slowly instead of a static plan image. Clay look in the site style: white/light grey model, soft shadows + ambient occlusion, thin dark edges, card background. Drawing-only projects keep their 2D image.
- **How:** `scripts/render_turntables.py` (PyVista + ifcopenshell, offline, render-time only) renders each IFC to a ~10 s seamless loop `web/public/turntables/<stem>.webm` + `<stem>.jpg` poster. Cards play it muted on loop (`<video>`), poster first, falls back to the old image if missing.
- **Files:** `scripts/render_turntables.py` (new), `web/public/turntables/` (new), `web/src/Projects.tsx` (Thumb only), `web/src/projects.css`.
- **Needs:** none.
- **Done when:** 9 BIM cards spin smoothly on Home; page stays light (lazy, small files).
- **Verify:** `python scripts/render_turntables.py`; `cd web && npm run build`; open Home.
