# T? dev.mjs: reinstall web deps when package-lock.json changes

- **Goal:** pulling a PR that adds an npm dependency must not break `node scripts/dev.mjs`.
- **Files:** `scripts/dev.mjs`.
- **Needs:** none.
- **Done when:** `npm ci` runs when `node_modules` is missing or older than `web/package-lock.json`; otherwise skipped.
- **Verify:** `touch web/package-lock.json && node scripts/dev.mjs --check` reports web deps stale.
