# T? Facts path: answer free-form questions over extracted facts

- **Goal:** judges type natural questions ("does this flat have a balcony?", "how big is the kitchen?", "how many storeys?"). Today ~2/3 of those return "no path could answer" because paths only parse dataset templates. New path: build a numbered fact list per drawing from our parsers (Swiss rooms/units/objects, detector boxes, IFC spaces/storeys/element counts, schedule tables), give it to Gemini with the question, it answers and cites fact ids → those become the evidence boxes.
- **Files:** `sitelens/paths/facts.py` (new), one line in `sitelens/router.py` (before vlm).
- **Needs:** none (uses GEMINI_API_KEY, model SITELENS_FACTS_MODEL default gemini-3.8-flash).
- **Done when:** a set of 20 free-form questions across sources is answered with evidence; scorer accuracy on dev not lower than before (path runs after the specific paths).
- **Verify:** `python ../junction-data/exp/general_qs.py` against the demo server.
