## Video production
- **Tools:**
  - Claude builds the video with Remotion in `video/`. Setup: `npx remotion skills add`.
  - Higgsfield for b-roll only (API, pay per use).
  - ElevenLabs voiceover (tech track).
- **Rules:**
  - Product footage = real screen recordings of the running UI. Remotion adds zooms on evidence boxes, callouts, captions, and the €/answer and accuracy charts.
  - Higgsfield: ≤15 s total (pain opener, building rising, hero close). Never generate product UI or results: the challenge grades verifiability.
  - Numbers on screen come from T10 results files, not typed by hand.
  - Render → check frames → fix before calling a cut done.
- **Structure (120 s):**
  - 0–12 pain (Higgsfield + VO)
  - 12–20 logo + one line
  - 20–95 four role vignettes, ~18 s each, one real question each
  - 95–110 accuracy + €/answer vs Gemini
  - 110–120 hero + call to action
- **Best practice:**
  - Pitch in the first 10 s.
  - Show the product, not slides.
  - Map visibly to the judging criteria: accuracy, verification, creativity.
  - Works muted: burned-in captions.
  - Readable at laptop size: zoom the UI, never full-frame 1080p.
- **Capture by Sat 22:00 (feature freeze):** clean UI recordings of each vignette, 1080p, no cursor jitter.
