# T? Detector on AECV-Bench: outside benchmark vs frontier VLMs

- **Goal:** third-party proof for the pitch. Score our detector path on AECV-Bench's 120 labelled floor plans and put it next to their published scores for about 29 VLMs.
- **Source:** https://github.com/AECFoundry/AECV-Bench (no LICENSE: evaluate only, never commit or redistribute their images). Clone outside the repo, like the Stoa dataset.
  - Data: `data/Use Case 1 - Object Counting/1 - Full Datasets/<id>/<id>.png` + `metadata.json` (`Door, Window, Space, Bedroom, Toilet`).
  - Their results: `benchmark_result_object_counting/<model>.csv` (`original`, `extracted`, `cost_usd`).
- **Files:** `eval/aecv.py` (new: runner + table), `eval/aecv_report.md` (new, results only). Don't change `sitelens/paths/detector.py`; if it needs changes, add a ticket.
- **Needs:** T6 (done). Weights `models/detector.pt` (ask johanseneuson).
- **Steps:**
  1. `AECV_DATA=<clone>/data/...` env var. For each plan, call the detector for door / window / toilet / bedroom / space counts.
  2. French room labels: map `CHAMBRE`→bedroom, `WC`/`BAINS`/`SDB`→toilet/bath. Report bedroom and toilet both with and without the map.
  3. Exact-match % per class + MAPE + €/plan. Recompute the VLM rows from their CSVs the same way (unparseable `extracted` = wrong).
  4. Write `eval/aecv_report.md`: one table, ours vs Gemini 3.5 Flash, Claude Fable 5, GPT-5.5, Gemma 4 31B. Date + commit.
- **Reference (computed 14 Nov from their CSVs, exact match):** Gemini 3.5 Flash door 43 / window 39 / space 14 / bedroom 93 / toilet 82, $3.77 per 120 plans. Gemma 4 31B 22/13/13/80/78, $0.02.
- **Expect:** a drop vs CubiCasa (French styles, other door/window symbols). Report honestly; a loss on some classes still makes the cost point.
- **Done when:** `eval/aecv_report.md` merged; one LOG line with the headline door/window numbers.
- **Verify:** `AECV_DATA=... python -m eval.aecv` reproduces the report.
