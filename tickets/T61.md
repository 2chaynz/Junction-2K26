# Projects workspace: project picker, per-project sheets and sessions

- **Goal:** the app opens on a project, like ACC/Procore. A Projects tab lists projects (BIM models, sheet sets, portfolios, archives); inside one, the explorer shows only that project's sheets in typed subfolders, plus its saved Ask sessions (past conversations), which reopen with their marks.
- **Files:** web/src/Projects.tsx, web/src/projects.ts, web/src/projects.css, web/src/Explorer.tsx, web/src/Chat.tsx, web/src/App.tsx, sitelens/sessions.py, sitelens/server.py, tests/test_sessions.py, CONTRACT.md
- **Needs:** T50
- **Done when:** Projects tab → open a project → explorer scoped to it with folders; ask → session saved server-side; Sessions list reopens it; switching project starts a fresh session.
- **Verify:** `node scripts/dev.mjs`, Projects tab → Clinic → ask → Sessions.
